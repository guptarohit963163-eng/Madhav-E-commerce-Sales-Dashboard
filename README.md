 Madhav-E-commerce-Sales-Dashboard

Project Overview

An interactive E-Commerce Sales Dashboard developed using Microsoft Power BI to analyze sales performance, profit, customer purchasing patterns and business trends.

Tools Used

- Microsoft Power BI
- Data Analysis
- Data Visualization

Project Objectives

- Analyze total sales and profit.
- Track monthly sales performance.
- Identify top-performing product categories.
- Analyze customer purchasing behavior.
- Understand payment method trends.

Dashboard Features

- Interactive charts and graphs
- Sales and profit analysis
- Category-wise performance
- Customer insights

Project Files

- Power BI Dashboard (.pbix)
- Dataset (.csv / .xlsx)
- Dashboard Screenshot

Key Learnings

Developed practical skills in data analysis, dashboard creation, data visualization and business reporting.
